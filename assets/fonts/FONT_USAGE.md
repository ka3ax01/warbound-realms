# Fonts for Warbound Realms MVP

Font binaries are not included in this archive.

Recommended setup:
- Main readable UI font: Noto Sans Regular / Medium / Bold
- Fantasy title font: Cinzel Decorative or Cinzel

Suggested placement after you download/install them locally:
- res://assets/fonts/noto_sans/
- res://assets/fonts/cinzel/

Rules:
- Use Noto Sans for garrison numbers, buttons, settings, level objectives.
- Use Cinzel/Cinzel Decorative only for title screens, Victory/Defeat headings, faction names.
