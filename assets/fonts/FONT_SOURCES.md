# Font Sources

Файлы шрифтов в архив намеренно не включены. Скачай их напрямую из официального источника и положи сюда.

Recommended:
- `Cinzel` — заголовки, экран победы/поражения, названия фракций
- `Inter` или `Noto Sans` — цифры гарнизона, кнопки, настройки, HUD
- `Uncial Antiqua` — только декоративный логотип или большие заголовки, не использовать для мелкого UI
