# Warbound Realms / Age of Banners — MVP Asset Starter ZIP

Это стартовый архив для Godot 4.x: структура папок, mapping, лицензии и простые авторские SVG-заглушки, чтобы разработчик мог сразу подключить ассеты и заменить их на финальные Kenney/KayKit/OpenGameArt файлы.

Важно: реальные сторонние asset-pack ZIP-файлы не вложены внутрь, потому что их лучше скачивать напрямую с официальных страниц автора и фиксировать версии/лицензии в `licenses/THIRD_PARTY_LICENSES.md`. Это снижает риск лицензионной каши перед Steam-релизом.

## Быстрый импорт в Godot
1. Скопировать папку `warbound_realms_assets_mvp` в `res://assets/` или распаковать содержимое внутрь `res://assets/`.
2. Использовать SVG-заглушки для прототипа.
3. После скачивания реальных паков заменить файлы по `ASSET_MAPPING.md`.
4. Обновить `licenses/THIRD_PARTY_LICENSES.md`.
